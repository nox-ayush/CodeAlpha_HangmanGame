A classic interactive, terminal-based **Hangman Word Guessing Game** built with pure Python. Developed as **Task 1** for the **CodeAlpha Python Programming Internship**

  ---

## 📌 Project Overview
The computer picks a random hidden word from a pre-configured dictionary. Your objective is to deduce the word letter-by-letter before running out of attempts!

  ---

## ✨ Key Features
  - 🎯 **Dynamic Difficulty Settings:**
  - **Easy:** 3 letters revealed at launch
  - **Medium:** 2 letters revealed at launch
  - **Hard:** Only 1 letter revealed at launch
  - 🕹️ **Turn Management:** Players are granted a maximum of **6 incorrect attempts** before gameover.
  - 🛡️ **Robust Input Sanitization:**
  - Prevents penalty on duplicate guesses.
  - Rejects numbers, spaces, and multi-character inputs cleanly.
  - 🧩 **Zero External Dependencies:** Built entirely with standard library tools.

  ---

## 🛠️ Tech Stack
  - **Language:** Python 3
  - **Libraries Used:** Standard `random` module
